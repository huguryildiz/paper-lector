# Problem card and candidate card

Use the fields that help. The researcher writes the question and the claim. Candidates proposed by AI are labelled speculative.

## Problem card

```
Name:
Status: lead, not a validated gap. Parameters: sourced / assumed / synthetic.
1. The decision: what, who decides, with what information, when
2. Why this differs from what is already solved, and what result it could change
3. What the papers read support (with locators) and what they do not
4. Smallest model: sets, inputs, variables, dynamics, constraints, objective, baselines
5. Claims phrased so they can be killed
6. Parameters a domain partner must supply, one sentence each on why
7. Risks: what a domain reviewer says first, what a method reviewer says first
```

## Candidate card

1. **What would we learn?** One question, its use, and a conditional sentence: "This study would establish whether or when [X] under [conditions] compared with [closest explanation]." Name the route.
2. **What supports it?** Papers and locators, the abstraction, the needed assumptions. Separate a known mechanism from an already-known conclusion. Include contrary evidence.
3. **What work would answer it?** Minimum model or data, objective, constraints, information, outputs, the strongest simple comparator, a reference bound if feasible.
4. **What could defeat it?** The strongest objection, a competing explanation, possible prior coverage, missing evidence. Say what a null result would still establish.
5. **What is the smallest useful test?** One bounded comparison or derivation, what each outcome means, the resources needed, and outcomes already seen.

Disposition: test next, verify a named fact first, or drop or reframe.
